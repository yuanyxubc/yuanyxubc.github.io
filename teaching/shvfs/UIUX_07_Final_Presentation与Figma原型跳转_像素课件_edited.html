STEP 3 · RETURN PATH

“返回”的两种表达

ACTION · BACK

回到刚才来自的界面

A → C ← B

同一页可能从不同入口进入时，Back 会尊重播放历史。

例：Item Detail 左上角返回
ACTION · NAVIGATE TO

去一个固定目的地

ANYWHERE → HOME

无论从哪里进入，都必须回到指定界面时使用。

例：完成装备后回 Character Equipped
测试动作：从两个不同入口进入同一页，再按 Back。若结果不一致，说明你需要固定 destination。

COMMON FAILURES

点不动时，按这个顺序查

01 · 没有蓝色节点切到 Prototype；选中真实图层，不是锁定对象。
02 · 点击区域太小连接整个 Button / Card，而不是文字或图标。
03 · Destination 找不到把目标做成顶层 Frame，并放在同一条 Flow 的 Page。
04 · 一播放就错页移动 Flow starting point；重启正确 Flow。
05 · Back 回到奇怪位置检查播放历史；必要时改为 Navigate to 固定页。
06 · 别人打不开检查访问权限，并复制 Prototype / Flow 直接链接。
